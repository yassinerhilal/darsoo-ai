# Darsoo AI — النسخة المحسّنة

## نشر مجاني عبر GitHub Pages
1. سجّل الدخول إلى https://github.com
2. أنشئ مستودعًا جديدًا باسم `darsoo-ai` واجعله Public.
3. ارفع `index.html` الموجود في هذا المجلد إلى جذر المستودع.
4. افتح Settings → Pages.
5. ضمن Build and deployment اختر Deploy from a branch، ثم `main` و`/(root)`، واضغط Save.
6. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages، غالبًا بالشكل:
   `https://YOUR-USERNAME.github.io/darsoo-ai/`

ملاحظة: هذا إصدار ثابت يعمل في المتصفح دون خادم. البحث يعرض المقاطع الأقرب من الدروس ولا يستخدم نموذج ذكاء اصطناعي خارجي. الدروس مخزنة محليًا في متصفح كل مستخدم، ولا تتم مشاركتها تلقائيًا بين الأصدقاء. لا تضع مفاتيح API سرية داخل HTML.
